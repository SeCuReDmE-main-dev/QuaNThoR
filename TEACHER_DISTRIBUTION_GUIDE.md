## 🚨 Troubleshooting

### **If Installation Fails:**
```
Common Issues & Solutions:

❌ "Python not found"
✅ Install Python from python.org (check "Add to PATH")

❌ "Permission denied"
✅ Right-click installer → "Run as Administrator"

❌ "Network error"  
✅ Check internet connection, try again

❌ Server won't start
✅ Make sure no other program uses port 5000
```

### **If Students Have Problems:**
1. First: Check `STUDENT_README.txt`
2. Try: Restart by running `START_QUANTHOR.bat` again
3. Last resort: Re-run `INSTALL_QUANTHOR.bat`
