# QuaNThoR - Student Quick Start Guide 
 
Welcome to QuaNThoR - Your AI-powered math verification tool! 
 
## How to Use: 
 
1. Double-click "START_QUANTHOR.bat" 
2. Wait for the server to start   
3. Open your web browser 
4. Go to: http://localhost:5000 
5. Start writing mathematical proofs! 
 
## Need Help? 
- The system will translate technical errors into plain English 
- AI assistance is built-in for learning 
- Contact your teacher if you have problems
